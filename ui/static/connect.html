Connect your own service

Three steps, no change to Argus itself.

1. Describe it

The wizard asks for the repo, the monitoring tool, the log files (it detects JSON and CSV formats) and the repro and test commands, then writes argus.yaml.

python -m connect.wizard new my_service

2. Check it

Validates every adapter and, with --full, runs the repro and tests once in the sandbox, exactly as a fix will be tested.

python -m connect.wizard check my_service --full

3. Point alerts at Argus

Add a webhook to Alertmanager or a Grafana contact point, or post the standard format from any script.

POST /alerts
