Welcome to Argus

When something breaks, Argus investigates, double-checks itself, tests a fix, and asks a person before changing anything.

How Argus works

Four steps, and a person always has the final say.

1
Looks into itReads the logs and recent changes to find likely causes.
2
Double-checksA second agent tries to prove each guess wrong. Only real evidence counts.
3
Tests a fixTries the fix in a safe copy and checks the problem goes away.
4
Asks youNothing changes until a person approves the fix.
